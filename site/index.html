Systems Engineering

Engineered without shortcuts.

Four decoupled subsystems designed to run high-performance WebAssembly inside modern Manifest V3 constraints.

01 / NETWORKING

MAIN-World WebSocket Tap

Injected at document_start before Lichess scripts initialize. Wraps native WebSocket to sniff round frames in capture phase without mutating data or sending frames.

02 / COMPUTE

Persistent Offscreen Host

Chrome MV3 service workers terminate every 30 seconds. FrameZero hosts Stockfish inside a persistent Offscreen document, preserving a 512 MB transposition table across matches.

03 / AUTOMATION

Chrome DevTools Protocol (CDP)

Dispatches native pointer events through chrome.debugger. Injected at the browser compositor level with isTrusted: true, bypassing synthetic DOM input blockers.

04 / ENDGAMES

Syzygy 7-Piece Tablebases

Inside 7 pieces, chess is mathematically solved. FrameZero skips heuristic search and queries Syzygy tablebases for provably optimal conversion using Distance to Mate (DTM).

Deployment

Install in 60 seconds

Runs unpackaged on any Chromium browser (Chrome, Brave, Edge, Arc, Opera).

STEP 01

Clone the Repository

Get the latest release bundle directly from GitHub to your machine:

git clone https://github.com/Mackming/framezero.git
STEP 02

Open Extensions Page

Navigate to chrome://extensions in your browser and toggle Developer mode in the top right.

STEP 03

Load Unpacked

Click Load unpacked and select the framezero folder. Open any Lichess analysis board to activate.
