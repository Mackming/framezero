// 03 // SYSTEMS ENGINEERING

FOUR CORE PILLARS

Engineered from the protocol level up to run persistent WebAssembly inside Chrome Manifest V3.

01 // NETWORKING document_start

MAIN-World WebSocket Tap

Patches window.WebSocket before Lichess scripts exist. Sniffs round frames in the capture phase without sending packets or modifying game state.

02 // COMPUTE 512 MB TT Resident

Persistent Offscreen Host

Overcomes MV3 service worker 30-second teardowns. Keeps Stockfish 19 WASM and its transposition table persistently warm across matches.

03 // AUTOMATION isTrusted: true

Chrome DevTools Protocol (CDP)

Dispatches native browser-level pointer events via chrome.debugger. Executes single-gesture drag-and-drops that bypass synthetic DOM blockers.

04 // ENDGAMES DTM Optimal

Syzygy 7-Piece Tablebases

Positions with ≤ 7 pieces skip heuristic search entirely. Queries public Syzygy servers for mathematically proven conversion using Distance to Mate.

> 05 // DEPLOYMENT

INSTALL IN 60 SECONDS

Runs unpackaged on any Chromium browser (Chrome, Brave, Edge, Arc, Opera).

01

Clone Repository

Get the release repository directly from GitHub to your machine:

git clone https://github.com/Mackming/framezero.git
02

Open Extensions Page

Navigate to chrome://extensions in your browser and toggle Developer mode in the top right.

03

Load Unpacked

Click Load unpacked, select the framezero folder, and open any Lichess board. Press Alt + B to toggle.
